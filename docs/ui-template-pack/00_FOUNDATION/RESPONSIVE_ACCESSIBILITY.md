# Responsive & Accessibility

## Breakpoints
- mobile <768
- tablet 768–1023
- desktop 1024–1439
- wide >=1440

## Rules
- Desktop is canonical for NOC/CDR/rate operations.
- At mobile, preserve critical status/identity and allow horizontal data-table access.
- Touch targets >=40px; prefer 44px.
- WCAG AA contrast.
- Visible keyboard focus.
- Text labels for semantic status.
- Long forms provide error summary + field errors.
- Critical charts have textual equivalents.
