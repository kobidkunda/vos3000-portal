# Typography

Use Inter for all product UI and tables. Use IBM Plex Mono only for technical identifiers.

## Scale
- Page title 24/700/32
- Section 18/600/26
- Card title 16/600/24
- Body 14/400/21
- Table 13/400-500/18
- Label 13/500/18
- Helper 12/400/17
- Badge 11-12/600/16
- KPI 28-32/700
- Technical 12-13/500/18

Numeric columns use tabular figures and right alignment.
Do not use display/marketing typography inside the operational application.
