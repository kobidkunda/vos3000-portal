# Data Density

This is a telecom operations product. Prefer useful density over oversized cards.

- Table text: 13px.
- Row height: 40–44px.
- Sticky headers for long operational tables.
- Numeric values right aligned.
- IDs/IPs/Call-IDs in IBM Plex Mono.
- Column chooser for dense tables.
- Server-side paging/filtering/sorting.
- Cursor pagination for very large CDR datasets.
- Never download millions of rows into browser memory.
